# Mannschaftskasse AI

Digitale Spielerkasse für Fußballvereine.

## Vision

Spieler, Trainer und Kassierer sollen Strafen, Trainings,
Spiele und Zahlungen zentral verwalten können.

## Geplante Funktionen

- Spielerverwaltung
- Strafenkatalog
- Trainingstermine
- Spieltermine
- Rollen & Rechte
- Authentifizierung
- Zahlungsübersicht
